LIFE QUEST デモ（アップロード用・軽量）

このフォルダだけを GitHub / サーバーへ上げれば遊べます。

- assets/backgrounds … QUEST背景（使用中のみ）
- assets/char-*.png … 使用中キャラのみ
- assets/title/keyvisual/kv-wide-a.jpg … タイトルKV
- assets/title/lifequest.png … KV元画像（バックアップ）
- assets/voices … ボイス
- assets/icon-*.png
